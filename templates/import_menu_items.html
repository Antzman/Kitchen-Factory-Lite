Spreadsheet Format

Include these column headings: Code, Name, Type, Category, Selling Price. The optional Active column accepts Yes or No and defaults to Yes when blank.

Type must be Ordinary Type or Prep Screen Item. Category names must already exist and be active under Settings → Menu Categories. Existing item codes and duplicate codes in the file are not imported. Recipe lines are managed separately on each menu item's Recipe tab.
